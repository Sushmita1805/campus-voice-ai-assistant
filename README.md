# campus-voice-ai-assistant
An interactive, multi-lingual Campus Voice AI Assistant for MITE built with OmniDimension, featuring real-time speech processing, anti-hallucination guardrails, and knowledge grounding across academic calendars, placements, and campus amenities.
Campus Voice AI Assistant is a real-time conversational agent designed for Mangalore Institute of Technology and Engineering (MITE). The system addresses common student, parent, and visitor inquiries regarding department locations, academic schedules, placements, and admission criteria. Built on a voice-first architecture using Sarvam STT, Cartesia TTS, and an LLM pipeline, the assistant features strict prompt guardrails and a dedicated knowledge base to deliver accurate information without hallucinating dates or policies.
